# Portfolio — Svitlana Design

Сайт-портфоліо UI/UX-дизайнерки. Next.js (App Router) + TypeScript + CSS Modules, деплой на Vercel.

- План сайту: [docs/site-plan.md](docs/site-plan.md)
- Перший екран зроблено за макетом у Figma (Desktop – 1).

## Запуск локально

```bash
npm install
npm run dev
```

Відкрити http://localhost:3000.

## Структура

- `app/page.tsx`, `app/page.module.css`: головна сторінка (перший екран).
- `app/globals.css`: кольори й шрифти з Figma (CSS-змінні).
- `public/images/`: фото й іконки, експортовані з Figma.
